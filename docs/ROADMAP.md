# 当前版本与后续路线

以 [2026-09-05 修整记录](RELEASE_2026-09-05.md) 为本轮功能和验收依据。

## 已实现

账号鉴权、上传归属、真实格式检查、内网下载拦截、内容转义与 CSP、积分流水和防重复到账、持久收费任务、画面工坊有界队列与重启恢复、管理员审计、站内反馈和回复、运营统计、完整备份校验与 Windows 定时备份。

界面保留创作输入；按账号隔离文字草稿和待处理任务；网络不确定时继续查原任务。生图结果区保持简洁，账目在个人中心，反馈在帮助中心。

## 当前部署

本机使用、卡密兑换模式。暂无正式 HTTPS 域名和异地备份位置。上线检查如实显示待配置项。

## 后续按真实需求推进

| 事项 | 启动条件 |
| --- | --- |
| 正式支付、回调验签、退款对账 | 确定在线收款并取得真实商户配置 |
| 异地备份 | 提供独立磁盘或受控网络盘位置 |
| 公网 HTTPS 部署 | 提供正式域名、证书和服务器配置 |
| 对象存储、多实例队列 | 当前单机容量或同时在线人数成为瓶颈 |
| 团队权限、复杂素材库、多模型市场 | 有明确付费用户需求后单独评估 |
